# Ansh Singh's Portfolio

This repository hosts the personal portfolio website of Ansh Singh, a CSE graduate specializing in compiler design, backend systems, and AI-integrated tools.

## Live Site
https://anshsingh24.github.io/

## What's Inside
- `index.html` – The main portfolio page with sections for About, Skills, Projects, Experience, and Contact.
- Styling – Custom CSS with a black-and-green coding theme.
- Projects – Featured projects include:
  - Task Management System (Spring Boot)
  - Weekly Bestseller Analytics Dashboard (Python/Streamlit)
- JavaScript – Interactive UI for adding/editing projects and experiences.

Feel free to explore the code and use it as a reference for building your own portfolio.
